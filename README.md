# N0AGI Homebrew tap

```
brew install n0agi/tap/termkick
brew install n0agi/tap/ytd
```

termkick is a free, native macOS SSH client and local terminal: your `~/.ssh/config`
hosts and local shells in tabs and split panes, with a snippets library and SSH key tools.
Signed and notarized by N0AGI LLC. Details: https://products.n0agi.com/termkick/

ytd is a free macOS menu-bar app that keeps a public or unlisted YouTube playlist downloaded
to a folder on your Mac, downloads single videos with one shortcut, and writes an on-device
summary and tags for every video. Not affiliated with or endorsed by YouTube or Google.
Signed and notarized by N0AGI LLC. Details: https://products.n0agi.com/ytd/

This tap holds install recipes only. The app downloads from products.n0agi.com.
